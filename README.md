# Hotel Link

A full stack hotel booking platform built using the MERN stack with a modular backend architecture inspired by modularity.

---

# Problem Statement

Traditional hotel booking systems are often difficult to scale because authentication, bookings, payments, and hotel management are tightly coupled inside a monolithic backend.

Users also face:
- Slow and outdated interfaces
- Poor booking workflows
- Limited scalability
- Hard-to-maintain backend systems

Hotel Link was created to solve these issues by building a scalable and modular hotel booking platform using the MERN stack while exploring backend structuring concepts.

---

# Motivation

The main motivation behind this project was to:

- Build a real-world MERN stack project
- Understand scalable backend architecture
- Improve frontend and backend integration skills
- Learn production-level API structuring
- Gain practical experience with authentication, payments, and bookings
- Understand how modern large-scale applications separate services

This project was built as a learning-focused implementation to understand how scalable full stack applications are designed in real-world environments.
